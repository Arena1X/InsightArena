================================================================================
KEY FEATURES
================================================================================

1. Time Window Protection
   - Withdrawals only before market.end_time
   - Enforced via MarketExpired error

2. Exact Fee Calculation
   - fee = withdrawal_amount * early_exit_fee_bps / 10_000
   - Conservation guaranteed: refund + fee = withdrawal_amount

3. Pro-Rata Distribution
   - Each participant gets: fee_share = total_fee * their_stake / remaining_pool
   - Incentivizes staying while rewarding commitment

4. Automatic Cleanup
   - Full exits remove predictor from market
   - participant_count decremented
   - Prediction record removed
   - UserProfile stats updated

5. Escrow Integration
   - Refunds released via standard escrow::release_payout()
   - Fund safety guaranteed
